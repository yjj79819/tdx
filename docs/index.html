🔑 设置同花顺Cookie

⚠️ GitHub Pages版无法在网页上设置Cookie，请在GitHub仓库中设置：
Settings → Secrets → Actions
添加密钥 THS_COOKIE，值为你的同花顺Cookie。
  1. 打开同花顺官网 https://ms.10jqka.com.cn/
  2. 按 F12 打开开发者工具
  3. 切换到 Console(控制台) 标签
  4. 输入 document.cookie 并按回车
  5. 复制输出的长字符串（以 v= 开头）
  6. 粘贴到GitHub Secrets中
